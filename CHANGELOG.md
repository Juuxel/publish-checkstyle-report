# Changelog

## Unreleased

## [3.0.0] - 2026-06-22

### Added

- [CodeNarc](https://codenarc.org/) XML report files are now supported in addition to Checkstyle reports.
  The action displays CodeNarc violations in the same way as Checkstyle errors and includes the priority level
  as well as the rule description in the check text.

### Changed

- Updated to Node 24 (#3)
